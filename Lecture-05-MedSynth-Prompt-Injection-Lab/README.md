# Lecture 5 — MedSynth: Breaking the Assistant

This package contains a deterministic Swagger lab for three direct
prompt-injection techniques using entirely fictional research.

## Folder use

- `student-inlab-files`: vulnerable FastAPI application and concise challenge
  instructions.
- `student-assignment`: one-page Attack Analysis Sheet.
- `ta-guide`: private working prompts, debrief answers, and defense demo code.

## Lab flow

```text
Baseline refusal
  ↓
Direct instruction override
  ↓
TA defense demonstration
  ↓
Persona switching
  ↓
TA defense demonstration
  ↓
Base64 obfuscation
  ↓
TA defense demonstration
  ↓
Layered security architecture
```

Students test through Swagger and do not modify source code.
